      Planes

      El plan es para TI — accountability. Después se divide en PRs pequeños que el review loop (/grebloop) puede cerrar.

      Comandos rápidos

      • /grebloop — auto-review hasta 5/5
      • /goal <estado> — define end state al estilo Codex
      • opensource <repo> — clona código en el workspace (terminal)
      • reference the codebase — tag para inline en prompts

      Skills disponibles

      Solo nombre + descripción están en contexto. El cuerpo se carga cuando el agente lo necesita (progressive disclosure).

        Orquesta de agentes

        Un agente principal; los sub-agentes solo aparecen cuando aportan productividad real.

          Composición del contexto

          Menos es más. Vigila lo que se inyecta en cada turno.

          Política

          Recomendado: desactivado. Sólo actívalo si tienes información propietaria que debe estar siempre presente.

          Como hacen Claude Code y Codex: comprime la conversación antes de que el modelo se degrade.

          Capa de memoria

          Hechos persistentes entre sesiones. NO viven en el contexto principal; se recuperan cuando son relevantes (igual que skills, progressive).
